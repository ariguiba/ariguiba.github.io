# ariguiba.github.io

My personal website, served by GitHub Pages at https://ariguiba.github.io

- `index.html`: all the content (look for the `EDIT:` comments)
- `style.css`: colours and layout (change `--accent` for your own colour)
- `script.js`: light/dark toggle, "Show all news", side rails
- `language-map.js`: the languages map; your languages and the map modes are set at the top
- `assets/map/`: country outlines and official-language data used by the map
- `assets/`: photo, CV and other files
- `archive/`: sections taken off the page (experience, education, projects, volunteering) to add back later

Preview locally: open `index.html` in a browser, or run `python3 -m http.server` here and visit http://localhost:8000
